# HaxBall Analytics LIVE — Render

## Local
1. Copie `.env.example` para `.env`.
2. Coloque seu token em `HAXBALL_TOKEN=...`.
3. Rode `npm install`.
4. Rode `npm start`.
5. Abra http://localhost:10000

## Render
- New -> Web Service
- Conecte este repositório
- Build Command: `npm install`
- Start Command: `npm start`
- Plan: Free
- Environment: `HAXBALL_TOKEN` = seu token
- Depois abra a URL `onrender.com`.

O token não deve ser commitado no GitHub.
